# SimpleCRM
Enterprise Customer Relationship Management System

## Overview
SimpleCRM is a powerful, local-first CRM application built with Python (Flask) and Vanilla JavaScript. It uses a custom file-storage engine using JSON and CSV to ensure zero external database dependencies.

## Architecture
- **Backend**: Python 3, Flask
- **Frontend**: HTML5, CSS3, Vanilla JS
- **Storage**: Local JSON / CSV files

## Setup
1. Create virtual environment: python -m venv venv
2. Activate environment: env\Scripts\activate (Windows) or source venv/bin/activate (Mac/Linux)
3. Install dependencies: pip install -r requirements.txt
4. Run application: python run.py

## Testing
Run pytest in the root directory.
